# What is this uassets folder?
It's uassets blueprints generated by Unreal Engine from each Unreal version from 4.0 to 5.8.

There is also text file from copy paste text when available.

All tests needs to pass each version from 4.0 to 5.8.

## bp_actor_empty
It's a blueprint Actor with no nodes.  

1. Right click and select `Blueprint Class`
2. Choose `Actor`
3. Rename to `BP_Actor_Empty` and open it
4. Click on Event Graph tab and remove 3 default event nodes
